# Portfolio V1 (archived)

The first version of Mauricio Moya's portfolio, frozen exactly as it was on 2026-11-04
(commit `3aa1116` of [maumoya.github.io](https://github.com/maumoya/maumoya.github.io)).

- Browse it: https://maumoya.github.io/portfolio-v1/
- Current portfolio: https://maumoya.github.io

## What V1 is

Plain HTML and CSS, no build, no tracking. One home page plus four area pages
(Development, Finance, Compliance, Education), project cards with short video loops.

## What changed from the original

Only two things, so this copy does not compete with the live site:

1. Each page carries `<meta name="robots" content="noindex">`.
2. The CI workflow was removed; this is a frozen snapshot, not maintained.

## What came after (V2)

Language menu (English, Chinese, Hindi, Spanish, Arabic, French, Portuguese, German, Elvish),
seven themes, calm optional sound, share previews and SEO metadata.
